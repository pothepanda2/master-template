# SOP-03 — Publish

**Audience:** café owner  
**When:** after any change you want tables to see.

## Why Publish exists

Studio is a draft on your phone. Tables only update when you tap **Publish**.

That is on purpose so you can fix five prices, then send them all at once.

## Steps

1. Finish your edits (dishes, categories, café, theme, CSV, logo).
2. Confirm the header shows **Unsaved changes**.
3. Tap **Publish**.
4. Wait until it says **Live for all tables** (and a time).
5. Open the public menu URL on another phone, or refresh a table phone.

Phones already sitting on the menu pick up the new version within about 20 seconds. If not, pull-to-refresh.

## Publish will refuse if

- A dish has no name — it jumps you to that dish.
- Café name is empty.
- WhatsApp is empty.

Fix those, then Publish again.

## What Publish does **not** do

- It does not change the Studio password (that saves on its own).
- It does not update GitHub or require a website rebuild.
- It does not send a WhatsApp to guests.

## If Publish fails

1. Check you are still unlocked (password). If it asks again, enter it and Publish.
2. Check the café phone has internet.
3. Wait a few seconds and tap Publish once more.
4. If it still fails, use SOP-08.
