# SOP-05 — Logo, theme, Instagram

**Audience:** café owner  
**When:** first setup, rebrand, or adding Instagram.

All of this is **Café** tab, then **Publish**.

## Logo (optional)

**No logo is fine.** The guest menu then shows the café name only — no empty box.

### Upload

1. Studio → **Café**.
2. **Choose logo** (or **Replace** if one is already there).
3. Pick a JPG, PNG, or WebP from the phone.
4. **Max 6 MB.** A typical phone photo is 2–4 MB.
5. The app shrinks it (about 512 px) so the menu stays fast.
6. **Publish**.

Square-ish works best (about 400×400). Busy full-store photos look muddy at small size.

### Remove

Café → **Remove** on the logo → **Publish**. Header goes back to name only.

Dish photos are still URL-only (or CSV `image` column). Only the **café logo** has a file picker.

## Theme

Café → **Look**. Six palettes:

| Theme | Feel |
| --- | --- |
| Warm cream | Paper, terracotta (default) |
| Dark | Black, lime |
| Coffee | Espresso, gold |
| Forest | Deep green |
| Rose | Dusty pink |
| Ocean | Teal |

Studio preview updates as you tap. Tables change only after **Publish**.

## Custom accent

Optional colour on top of the theme (picker or 6-digit hex, e.g. `#C45C26`).  
**Default** restores the theme’s own accent.

Veg / non-veg marks and the WhatsApp green **do not** follow the accent. Those stay so guests can still read diet and chat.

## Instagram (optional)

Paste the profile URL on the Café tab, e.g. `https://instagram.com/yourcafe`.

Then Publish. A small **Instagram** chip appears:

- Top, next to Directions
- Footer, next to WhatsApp

No URL = no buttons. Do not paste a login page or a single post unless you mean that.

## Google Maps

Paste the Maps share link on the Café tab. **Directions** on the guest menu uses that. Empty = no Directions button.
