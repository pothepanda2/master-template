# Café owner — QR menu quick card

Keep this on the manager phone.

## Two links

- **Menu (customers / QR):** the site address you were given — no `/studio`
- **Studio (you only):** same address + `/studio`

## Password

Unlocks Studio only. Guests never type it.  
Change it in Studio → **Café** → Change password.

## Daily rule

**Nothing reaches the tables until you tap Publish.**

Top of Studio:

- **Unsaved changes** → tap **Publish**
- **Live for all tables** → guests have this version

Then open the **menu** link on another phone and check one price.

## Common jobs

| Job | Where | Then |
| --- | --- | --- |
| Change price | Dishes → tap dish → ₹ | Publish |
| Add dish | Dishes → Add dish → optional photo | Publish |
| Sold out | Dish → Available off | Publish |
| Hours / WhatsApp | Café tab | Publish |
| Logo / dish photo / colours | Café or dish | Publish |
| Many prices | Dishes → Export / Import CSV | Publish |

## Photos

- **Logo:** Café → Choose logo. Max **6 MB**. No logo = name only.
- **Dish:** Open the dish → Choose. Max **4 MB**. We shrink both.

## Do not

- Do not print `/studio` on table QR codes
- Do not leave Studio unlocked on the counter (use the lock icon)
- Do not tap **Reset to The Cafe Store** or **Load Hashtag Cafe demo**
- Do not import CSV with **Replace all dishes** unless you exported a backup first

## WhatsApp number

Digits with country code, example `91XXXXXXXXXX`. No call button on the menu.

## If tables look old

1. Did you Publish?  
2. Refresh the customer phone.  
3. Confirm they scanned the menu link, not Studio.
