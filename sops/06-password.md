# SOP-06 — Studio password

**Audience:** café owner  
**When:** first login, new manager, or you think someone else has the link.

## What the password does

It locks **Menu Studio only**. Guests never type it. The public menu stays open.

Anyone with both the Studio link **and** the password can change the live menu (after Publish).

## First time (new site)

1. Open `/studio`.
2. Set a password (4–64 characters) and confirm it.
3. Save it in the café’s password notebook / manager WhatsApp — not on a sticky note on the counter.

The first person to open Studio on a brand-new site is the one who sets it. Do this with the owner, not a random staff phone.

## Unlock

1. Open `/studio`.
2. Enter the password.
3. Stay on that browser; it remembers you for about **12 hours**.

If you already used a 4-digit PIN on an older version, type those same 4 digits — it still works until you change it.

## Change password

1. Unlock Studio.
2. **Café** tab → **Change password**.
3. New password twice (at least 4 characters).
4. Save.

This takes effect immediately. You do **not** need Publish for a password change. Other devices must unlock with the new password.

## Lock the phone

Header **lock** icon. Use this before handing the café phone to a waiter or leaving Studio open on the counter.

## If the password is lost

The lock lives in the site’s live store, not in the dishes. You cannot recover it from the guest menu.

Contact the person who launched the site (agency). They can reset the Studio lock on the hosting side. Do not try to “guess and Publish” — Publish is blocked while locked.

## Do not

- Do not send the Studio link in the same message as the password.
- Do not use `1234` or the café Wi‑Fi password.
- Do not leave Studio unlocked on a shared tablet.
